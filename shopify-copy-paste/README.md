## Paste into Shopify (no app)

For each product:

1. Shopify Admin → **Products** → open the product.
2. In **Media**, delete the old product shots. **Keep the last how-to / infographic slide.**
3. Upload the matching JPEGs from this folder (or the zip).
4. Drag them into the same order as the live gallery (hero first).
5. **Save**.

Do not replace how-to slides or 7-colour infographic slides. Regenerating those wrecks the text.

## Photo rules (for later edits)

- If something is wrong, **fix only that issue**. Do not change angle, shape, or background unless asked.
- Studio charcoal is about `#2A2A28`, not pure black.
- No dirty cutout fringe, leftover cyan UI boxes, leftover script text, or white wireframe ghosts.
- Do not put tools back in boxes.
- `tool-scalp` is the **Heatless Curl Set**. Slide 1 (`tool-scalp.jpg`) is silicone comb massagers, not the LED oval wand.
- `tool-scalp-comb` is the **Electric LED Scalp Massager** (elongated oval LED wand). Do not redesign it as a 3-comb set.
- Gua sha screen: white digit **9** only. No MODE / SPEED text.
- Sponges: **exactly 12**.
- Latest request for curls + ice roller: **no floor / contact shadow**. This pack may still have older shadows on some of those slides; Cloud Agent artifact storage dropped the later no-shadow reshoot.
