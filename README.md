# LUMEN Lab

Flashy, responsive **glow tools** e-commerce demo built for Shopify upload.

- **Niche:** Beauty tools only (LED, stone, silicone, kits) — **locked** in [`docs/NICHE_PICK.md`](docs/NICHE_PICK.md)
- **Brand:** LUMEN (mint/cyan site)
- **Pages:** 10
- **Products:** **20** tools in [`js/products.js`](js/products.js)
- **Cart:** Working demo (localStorage)

## Quick start

Open [`index.html`](index.html) or [`shop.html`](shop.html) in your browser.
